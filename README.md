## 🎯 What Does SmuggleMyPayload Do?

In plain words: it builds HTML files that contain hidden, embedded data. When opened in any web browser, that data is reconstructed back into the original file. This is called **HTML Smuggling**, a technique used by security researchers to understand how attackers might hide payloads.

This toolkit gives you:
- **Multiple techniques** – Several ways to hide and rebuild files.
- **Encoding options** – Choose how your data is packed (like choosing a suitcase vs. a box).
- **JavaScript variations** – Different "engines" that power the rebuilding process.
- **Ready-made templates** – Pre-designed starting points so you don't start from scratch.

You don't need to understand any of the technical details. Just pick a preset, add your file, and generate your HTML.

## 🛠️ Troubleshooting & Tips

**"My browser blocked the HTML file."**
Some browsers are cautious with auto-executing scripts. Try a different browser, or use the "simple" template which is more compatible.

**"The generated file is too big."**
Try a different encoding option. Some methods compress better than others.

**"Where are my output files?"**
Files are saved in the same folder as the program. Look for files starting with `output_` or `payload_`.

**"It doesn't work on mobile?"**
Mobile browsers are stricter. This toolkit is optimized for desktop browsers like Chrome, Edge, or Firefox.
